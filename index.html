    Ethical Hacking¶

    Hands-on · CEH-aligned

    Attack it. Defend it. Report it.¶

    A hands-on, CEH-aligned introduction to ethical hacking — you'll scan, test, exploit, and secure systems in a safe virtual lab, then learn to write up what you found like a professional.

    4.5 units 48 lecture + 18 lab hrs CEH exam-aligned Hands-on ACI Skill Labs Open-access readings — $0

    Weekly schedule¶

    The course follows the real attacker's kill chain across five phases, covering the full set of CEH topic areas. Each week is a single notes page with its reading and a link to that week's hands-on ACI lab.

    What you'll be able to do¶

    By the end of the quarter you will be able to demonstrate the ability to attack and defend a network — the course's core learning outcome — and you'll be prepared for the Certified Ethical Hacker (CEH) exam. Concretely, you'll be able to:

    • Conduct reconnaissance and map a target's attack surface.
    • Scan and enumerate hosts, services, and vulnerabilities.
    • Exploit systems and web applications in a controlled lab.
    • Recognize and reason about malware, DoS, and social-engineering attacks.
    • Apply cryptographic concepts and evade basic network defenses.
    • Plan a penetration test and write a professional findings report.

    How the course is delivered¶

    Three moving parts

    Lecture (concepts, in class) · Labs (hands-on, ACI Skill Labs) · Reading (free, open-access — linked on every week page). There is no textbook to buy.

    • Hands-on labs run on ACI Skill Labs. Every lab includes a guided walkthrough, a live virtual machine, and auto-graded checkpoints.
    • Readings are all free and open-access — NIST guides, OWASP, the official Nmap book, Crypto 101, Metasploit Unleashed, and more. See the Free Resource Library.
    • Ethics and law run through the whole course, anchored by Alana Maurushat's open-access Ethical Hacking.

    Authorization first

    Everything in this course is practiced only inside the provided lab environment or on systems you have explicit written permission to test. Unauthorized access to computer systems is a crime. You'll sign an acceptable-use agreement in Week 1.
