# Free Resource Library

Every reading in this course is free and open-access. No textbook required. Bookmark this page.

## Ethics, law & methodology

- **Alana Maurushat, *Ethical Hacking*** (University of Ottawa Press, 2019) — open access. [Publisher](https://press.uottawa.ca/en/9780776627946/ethical-hacking/) · [Full PDF (OAPEN)](https://library.oapen.org/bitstream/id/ab438eb4-5f5d-4509-8c0b-f6c57f271e84/9780776627922.pdf)
- **NIST SP 800-115** — *Technical Guide to Information Security Testing and Assessment.* [PDF](https://nvlpubs.nist.gov/nistpubs/legacy/sp/nistspecialpublication800-115.pdf) · [CSRC page](https://csrc.nist.gov/pubs/sp/800/115/final)
- **Penetration Testing Execution Standard (PTES).** [pentest-standard.org](http://www.pentest-standard.org/index.php/Main_Page)
- **OSSTMM** — Open Source Security Testing Methodology Manual. [isecom.org](https://www.isecom.org/OSSTMM.3.pdf)

## Reconnaissance & scanning

- **Nmap Network Scanning** (official book). [nmap.org/book](https://nmap.org/book/toc.html)
- **OSINT Framework.** [osintframework.com](https://osintframework.com/)
- **Wireshark User's Guide.** [wireshark.org/docs](https://www.wireshark.org/docs/wsug_html_chunked/)

## Exploitation & tooling

- **Metasploit Unleashed** (OffSec, free). [offsec.com/metasploit-unleashed](https://www.offsec.com/metasploit-unleashed/)
- **Kali Linux Revealed** (official, free). [kali.org book](https://www.kali.org/download-kali-linux-revealed-book/)

## Cryptography

- **Crypto 101** (free book). [crypto101.io](https://www.crypto101.io/)

## Web application security

- **OWASP Top 10.** [owasp.org/www-project-top-ten](https://owasp.org/www-project-top-ten/)
- **OWASP Web Security Testing Guide (WSTG).** [owasp.org/www-project-web-security-testing-guide](https://owasp.org/www-project-web-security-testing-guide/)
- **OWASP Cheat Sheet Series.** [cheatsheetseries.owasp.org](https://cheatsheetseries.owasp.org/)

## Wireless

- **Aircrack-ng documentation.** [aircrack-ng.org/documentation](https://www.aircrack-ng.org/documentation.html)

## Frameworks & reference

- **MITRE ATT&CK.** [attack.mitre.org](https://attack.mitre.org/)
- **CISA — DoS & phishing guidance.** [cisa.gov](https://www.cisa.gov/)
- **CyBOK — Cyber Security Body of Knowledge** (free, university-level). [cybok.org](https://www.cybok.org/)

## Optional free video

- **freeCodeCamp** — full ethical-hacking courses on YouTube.
- **Professor Messer** — free foundational security training. [professormesser.com](https://www.professormesser.com/)
