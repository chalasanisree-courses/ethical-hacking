# Site source (MkDocs)
Editable source for the Ethical Hacking site. The built site is at the repo root (Pages serves it).
Edit files under `docs/`, then from this `source/` folder run `mkdocs build` (needs `pip install mkdocs-material`),
and copy the generated `site/` contents to the repo root. Do not hand-edit the built HTML at the root.
